# Authoring

Skills for reading, understanding, and writing agent skills.

- **[yumia-skill-writer](./yumia-skill-writer/SKILL.md)** — Reads and interrogates source material,
  reaches a precise understanding, then drafts or refines a coding-agent skill that works in a real
  pipeline.
- **[project-orientation](./project-orientation/SKILL.md)** — Builds and maintains a repository's
  orientation layer — mental model, vocabulary, routing, invariants, and decisions — then uses it to
  catch drift before it becomes a bug.
