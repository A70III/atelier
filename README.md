# atelier

Agent skills loaded by coding agents — a small workshop of specialists for writing skills,
orienting agents in repositories, designing interfaces, and migrating brands.

## Install

```bash
npx skills add A70III/atelier
```

Works with Claude Code, Cursor, Codex, pi, and every other agent supported by the skills CLI.

## Layout

Skills live under `skills/`, grouped into buckets:

- `authoring/` — reading, understanding, and writing agent skills
- `design/` — web interface design and audit
- `engineering/` — repository-wide engineering migrations

Each skill is its own directory containing a `SKILL.md` (with YAML frontmatter — `name` and
`description`) plus any bundled references and scripts.

## Skills

### Authoring

- **[yumia-skill-writer](./skills/authoring/yumia-skill-writer/SKILL.md)** — Reads and interrogates
  source material (Markdown, specs, notes, transcripts, PDFs), reaches a precise understanding, then
  drafts or refines a coding-agent skill that works in a real pipeline. Interviews before writing,
  and verifies against a validator and audit checklist before shipping.
- **[project-orientation](./skills/authoring/project-orientation/SKILL.md)** — Builds and maintains a
  repository's orientation layer — mental model, vocabulary, routing, invariants, and decisions —
  then uses it to catch drift before it becomes a bug.

### Design

- **[frontend-designer](./skills/design/frontend-designer/SKILL.md)** — Designs, builds, and audits
  web interfaces so the result reads as designed for its subject instead of generated by default.
  Forces a written direction record, a plan reviewed against the brief, and a gated pre-flight
  before any UI is called done.

### Engineering

- **[rebrand](./skills/engineering/rebrand/SKILL.md)** — Safely rebrands a product across a
  repository: audits every old-brand occurrence, replaces only the safe ones, and validates the
  result. A controlled migration, not a search-and-replace. Invoke as
  `/skill:rebrand OldName -> NewName`.

## Adding a skill

Drop the skill folder under the matching bucket in `skills/` and link it from the top-level
`README.md` and from that bucket's `README.md`. The directory name must match the `name` field in
the skill's `SKILL.md`.
